# RMUTT ROBOT ACADEMY 2026

ระบบบริหารค่าย สื่อการเรียนรู้ ทีม การแข่งขัน คะแนน และจอแสดงผล

## เทคโนโลยี
PHP, MySQL/MariaDB, HTML, CSS และ JavaScript

## ชุดซอร์สโค้ดสำหรับ GitHub
- มีโครงสร้างฐานข้อมูลใน database/ และตัวอย่างตั้งค่า config/local.example.php
- ไม่รวม config/local.php ฐานข้อมูลที่มีข้อมูลจริง ไฟล์อัปโหลด และสคริปต์ที่มีรายชื่อผู้เข้าร่วม
- ต้องมีเว็บเซิร์ฟเวอร์ที่รองรับ PHP และ MySQL/MariaDB เพื่อใช้งาน ไม่สามารถรัน PHP ผ่าน GitHub Pages
- การนำโค้ดขึ้น GitHub ไม่ได้ทำให้ฐานข้อมูลหรือเว็บขึ้นโฮสต์โดยอัตโนมัติ
- สำรองฐานข้อมูลเดิมก่อนเปลี่ยนระบบ และอย่านำไฟล์สำรองข้อมูลจริงขึ้น repository
